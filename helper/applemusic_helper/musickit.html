Connect Apple Music to Lyrion Music Server

This helper streams via the Apple Music web player. It needs your account's media‑user‑token, which you copy from a signed‑in music.apple.com browser tab. Stored only in the helper's config file.

1 · Sign in at music.apple.com

  1. Open music.apple.com in this browser and sign in (the Apple ID with your subscription).
  2. Open developer tools → Console (⌥⌘J / F12).
  3. Paste this and press Enter:
    copy(MusicKit.getInstance().musicUserToken)
    It copies the token to your clipboard. (If copy() is unavailable, run MusicKit.getInstance().musicUserToken and copy the quoted string.)

2 · Paste it here

Enter a token to continue.

Why not a normal "Sign in with Apple" button?

The helper uses the web player's developer token, which Apple locks to apple.com. MusicKit's popup sign‑in only works on that origin, so the token is copied manually instead. If you have your own Apple Developer MusicKit key you can set developer_token + developer_token_manual in the config and the origin lock goes away.
